## Como resolver

A política de egresso do ambiente Claude Code na web bloqueia conexões HTTPS de saída para domínios externos não autorizados. Para que a curadoria funcione, é necessário uma das seguintes ações:

1. **Executar o script localmente** — rodar `python3 fetch_feeds.py` na sua máquina, onde não há restrição de rede.
2. **Configurar uma GitHub Action** — mover a curadoria para um workflow do GitHub Actions, que tem acesso irrestrito à internet.
3. **Solicitar liberação de domínios** — pedir à administração do ambiente que libere os domínios dos feeds RSS na política de egresso.
