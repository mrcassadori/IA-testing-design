# Curadoria de Conteúdo — 2026-09-01

> **Aviso:** Nenhum artigo pôde ser coletado nesta execução.

## Motivo

O ambiente de execução remota (Claude Code on the web) bloqueou todas as requisições de saída para os feeds RSS listados em `feed.txt`. O proxy de rede retornou `403 Forbidden` para todos os domínios, incluindo:

- nngroup.com
- uxdesign.cc
- uxplanet.org
- smashingmagazine.com
- alistapart.com
- mindtheproduct.com
- towardsdatascience.com
- technologyreview.com
- wired.com / fastcompany.com / theverge.com
- hnrss.org
- behavioraleconomics.com
- productcoalition.com
- servicedesignshow.com

## Como resolver

Para que a curadoria funcione, é necessário uma das seguintes ações:

1. **Alterar a política de rede do ambiente** no painel do Claude Code on the web, habilitando acesso a domínios externos (RSS feeds). Consulte: https://code.claude.com/docs/en/claude-code-on-the-web
2. **Executar localmente** via Claude Code CLI, onde não há restrições de egress.
3. **Usar um script intermediário** (ex.: `fetch_feeds.py` já presente no repositório) rodando em um servidor ou GitHub Actions com acesso à internet, que gera o arquivo de conteúdo; o Claude então apenas curadoria/formata.
