### Causa

O ambiente de execução remota (Claude Code na nuvem) roteia todo o tráfego HTTPS por um proxy com política de egresso restritiva. Todos os domínios acima foram bloqueados com `connect_rejected` (403 Forbidden no túnel CONNECT).

### Ação recomendada

Para restaurar a curadoria automática, uma das seguintes ações é necessária:

1. **Liberar os domínios** na política de egresso da sessão agendada (requer acesso ao painel da organização no Claude Code).
2. **Migrar o pipeline** para um ambiente com acesso de rede irrestrito — ex.: GitHub Actions com `fetch_feeds.py`, um servidor próprio com cron job, ou Vercel Cron Functions.
3. **Alternativamente**, configurar um servidor intermediário (ex.: Cloudflare Worker ou Pipedream) que agregue os feeds e exponha um endpoint acessível pelo proxy.
