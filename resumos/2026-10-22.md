## O que fazer

Para que a curadoria funcione, o ambiente de execução da tarefa agendada precisa ter **acesso de rede aos hosts dos feeds RSS**.

**Opções:**
1. **Reconfigurar o ambiente** no painel do Claude Code para permitir acesso de saída a hosts externos (política de rede menos restritiva).
2. **Executar localmente**: rodar o script `fetch_feeds.py` na sua máquina, onde não há restrição de proxy.
3. **Usar um GitHub Action**: configurar a tarefa como uma GitHub Action, que tem acesso irrestrito à internet.

Referência: a política de proxy do ambiente está em `/root/.ccr/README.md` — erros 403 indicam hosts não permitidos pela sessão.
