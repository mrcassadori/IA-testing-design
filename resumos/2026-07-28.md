### Causa raiz

A sessão Claude Code (cloud) opera com uma política de egress restrita que bloqueia requisições CONNECT para hosts externos não autorizados. O proxy retornou `403 Forbidden` para todas as tentativas — isso é uma restrição de rede da plataforma, não um erro dos feeds.

Esta é a **segunda ocorrência consecutiva** deste bloqueio (também ocorreu em 2026-07-27).

### Como resolver

Para que a curadoria funcione em sessões cloud, é necessária uma das opções:

1. **Executar o script localmente** (`python3 fetch_feeds.py`) e fazer commit/push manual.
2. **Usar um GitHub Action** para rodar a curadoria em um runner com acesso à internet irrestrito.
3. **Configurar o ambiente cloud** com permissões de rede ampliadas para as origens dos feeds RSS.
