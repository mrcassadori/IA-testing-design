## Como Resolver

O ambiente de execução remoto (Claude Code na web) aplica uma política de egresso de rede que bloqueia conexões HTTPS a domínios externos não autorizados. Para restaurar a curadoria, uma das opções abaixo é necessária:

1. **Migrar para GitHub Actions** — executar o script `fetch_feeds.py` em um workflow do GitHub, que tem acesso irrestrito à internet.
2. **Executar localmente** — rodar `python3 fetch_feeds.py` na máquina local e fazer commit/push do arquivo gerado.
3. **Adicionar os domínios à allowlist** — se a política de egresso do ambiente puder ser configurada, incluir os domínios dos feeds na lista de permissões.
